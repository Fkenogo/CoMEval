# CoMEval agent instructions

## START-01

Before work, read the Master Programme, product foundation and relevant pilot acceptance cases. Record the task authority, observation time, refreshed remote main SHA, working branch/head and merge base, dirty state and worktrees, relevant PRs, approved experience reference, active entry points and preview identity if relevant. Identify where to start, what stale source to avoid, unresolved differences, and the scoped verdict. An older remote source tree must never silently replace accepted prototype behaviour. Pause affected work when the source or authority is unresolved.

Use fictional fixtures in this public repository, including in branches, PRs and test output. Keep client identities, source links, project configuration derived from restricted material, evidence, participant data and credentials in authorised private locations. Use scoped project membership in designs and verify it at each data and evidence boundary.

At handover record exact SHAs, PR, verification, limitations, remaining decisions and the next verified starting point. Record implementation, acceptance, merge and deployment separately.
