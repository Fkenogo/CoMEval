# CoMEval

CoMEval is a Miledge Ventures shared product in development for monitoring and evaluation teams. It connects project plans, field capture, evidence review, reporting and follow-up. Each project configures its own forms and indicators and uses the same workflow.

## Project home

- [Master Programme](docs/governance/CME-000-MASTER-PROGRAMME.md) — status, sequence and decision owners
- [Product Foundation](docs/product/CME-001-PRODUCT-FOUNDATION.md) — product scope and reporting rules
- [Pilot and acceptance](docs/pilot/CME-002-PILOT-AND-ACCEPTANCE.md) — two use cases and first build brief
- [Agent instructions](AGENTS.md) — starting point and handover checks

The application in this repository is an experience prototype. See the Master Programme for the tested baseline and implementation status.
